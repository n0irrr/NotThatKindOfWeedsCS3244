# Iteration Log

One row per experiment. Change **one factor at a time** so improvements are attributable.

Every run uses the authors' split as published on Kaggle (`labels/*_subset0.csv`, fold 0;
`src/data/kaggle_split.py` -> `data/splits_kaggle0/`): 10,501 train / 3,501 val / 3,507 test, no image in
two splits. Each CNN's augmentation was chosen on validation data in earlier tuning runs, before the
final runs; k, C and the best epoch are picked on val. Test is reported for every row and chose
nothing. Rows 12-13 (test-time augmentation and the seed ensemble) were chosen on val before test
was scored.
